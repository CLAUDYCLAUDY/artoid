Bienvenue

Gérez le catalogue, les photos et les images du site. Rien à installer, rien à coder.

  1. Connectez-vous une fois avec votre clé GitHub (bouton ⚙).
  2. Choisissez un ouvrage ou un objet, ou cliquez sur + Ajouter.
  3. Déposez vos photos, remplissez les champs.
  4. Cliquez sur Publier : le site est à jour en une minute.
Sur iPhone, ajoutez cette page à votre écran d'accueil (bouton Partager → « Sur l'écran d'accueil ») : elle s'ouvrira comme une application.

Prêt.
